01 / BACKGROUND & MISSION

立项背景：破除政务数字化的四大深层壁垒

拒绝无意义 AI 套话，直击老百姓办事与政务问答的核心矛盾
PROBLEM VS SOLUTION
现行政务咨询的典型困境
1. 公文严谨但极其晦涩
红头文件条文交叉、术语繁复，群众看不懂资格准入，算不清补贴标准。
2. 通用大模型事实性幻觉
公有大模型无中生有编造已废止政策，严肃政务场景下行政合规风险容错率为 0。
3. 频繁外部跳转打断流程
传统机器人动辄抛出外部长链接，导致群众在不同系统间迷失甚至流失。
4. 追问断层与指代丢失
市民口语化追问常省略主语（如“外地人可以吗”），传统系统无法记忆上下文。
本系统的工程解法与原则
• 老百姓大白话智能翻译
AI 自动将公文法律条款拆解为：资格门槛、待遇标准、办事要点与注意事项。
• 权威公文 100% 精准直溯
RAG 检索增强引擎严格锚定发文字号（如穗府办规〔2024〕6号），支持原文核验抽屉。
• 纯文字沉浸式流程向导
彻底剔除外部跳转死链，三步走文字指引：资格自查 ➔ 免交材料 ➔ 线上/线下路径。
• Spring AI 会话持久化与多轮指代消解
基于 H2 数据库 Session Memory，自动将前序问答注入上下文，无缝理解省略追问。
宗旨对齐：对齐广东省“粤省事”与广州市“穗好办”移动政务服务规范 第 2 / 8 页

公文法条原文（专业但晦涩）

【准入条件】 • 户籍：广州本市户籍 或 持有效广东省居住证（外地人也可申请） • 社保：在广州连续缴纳社保满 6 个月 • 住房：在广州市内名下无任何自有房产 【补贴标准】 • 金额：300 元 / 月 • 周期：最长享受 24 个月（共计最高可领 7,200 元）

05 / FRONTEND ENGINEERING

ZERO EMOJI & SHARP CORNERS
Shadow DOM 物理隔离
真实广州政务网（gz.gov.cn）的既有样式表极其庞大复杂。传统脚本注入必然导致 CSS 冲突或样式变形。

本项目使用 Web Components 的 Shadow DOM 树 进行沙盒级样式隔离，确保助手在任何外部网站均自洽稳定。
ZERO CSS POLLUTION
严肃政务视觉体系
• 全直角公文风：全局统一采用 border-radius: 0，呈现公文严谨规范；
• 严格 0 Emoji、0 卡通：彻底抛弃轻浮的聊天表情包与 3D 黏土小人插画；
• 常驻“快速答疑”徽标：克制深蓝底色与单行最简复制按钮。
GOV DOCUMENT SPEC
纯文字三步向导
彻底剔除外链跳转，以三步纯文字向导卡片闭环：

步骤一：资格自查（准入条件核验）
步骤二：材料清单（标注免交证照）
步骤三：办事指引（线下窗口地址与“穗好办”小程序线上精确路径）。
ZERO REDIRECTS
