方案一：油猴插件挂载测试（推荐）
无感伴随
1
安装浏览器扩展
确保 Chrome / Edge 浏览器已安装 Tampermonkey（油猴）或 ScriptCat（脚本猫）插件。
2
一键安装政务助手用户脚本
点击下方按钮直接打开脚本源码，在弹出窗口中点击“安装”。
一键安装 gz_gov_ai_assistant.user.js
3
打开真实广州政务网站直接测试
安装完成后，访问任意真实官方页面，页面右下角将自动唤起“广州政务 AI 智能助手”徽章：
访问 广州市人民政府门户网站 (www.gz.gov.cn) 访问 广东政务服务网广州分厅 (www.gdzwfw.gov.cn/?region=440100)
方案二：控制台注入测试（免装插件）
即开即测
1
打开任意真实政务页面
在浏览器中打开真实政务网站，如广州市人民政府网政策页面或办事窗口。
2
打开开发者工具 Console 控制台
在目标政务网页上按键盘 F12 键（或点击鼠标右键选择“检查”），切换到 Console（控制台）面板。
3
复制并执行一行注入脚本
将下方代码复制并粘贴到控制台回车，即可瞬间挂载助手并在真实政务页面上展开交互测试：
const s=document.createElement('script');s.src='http://localhost:8080/gz_assistant_embed.js';document.body.appendChild(s);
