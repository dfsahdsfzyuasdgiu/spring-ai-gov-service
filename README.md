## 一、 项目定位与分工协作

本项目为**广州市政务服务与政策法规 AI 智能专窗**的前端交付成果，专注于以**无感伴随式浏览器插件（Tampermonkey UserScript）**与**网页嵌入脚本（Web Embed）**的形式，赋能广州市各级政务门户网站，为市民与企业提供“查政策、办政务、找入口、解疑难”的一站式民生智能导办体验。

### 团队敏捷协同分工
* **前端研发（本项目仓库）**：
  - 负责纯前端浏览器扩展插件的架构设计、组件化与交互体验实现；
  - 1:1 复刻广州政务官方“叻仔”视觉体系与适老化字号无级缩放；
  - 采用 Web Component / Shadow DOM 技术实现样式与 DOM 物理隔离，确保零样式冲突挂载于任意官方政务网站；
  - 深度对接云端 Dual-Agent 引擎的 SSE 全生命周期事件流，内置轻量级政务 Markdown 引擎，实现打字机流式渲染、自适应政务表格、一键申报直达、意图消除歧义交互、政策公文法定溯源及广东政务服务网直达导航。
* **云端后端与知识库研发（团队协同）**：
  - 部署于云端高性能服务器（`http://149.118.133.163:6001`）；
  - 负责双智能体协同架构（导办 Agent + 政策 Agent）、Milvus 向量数据库与知识切片检索、大模型推理及 SSE 事件流下发。

## 二、 核心特性与功能全览

### 1. 静默待命模式（默认不自动弹出，随需唤出）
- 刚进入广州市政府门户网站时，对话主窗口**默认处于静默收起状态**，绝不遮挡官网首页头条、通知公告与主导航；
- 仅在屏幕右下角驻留一枚小巧精致的官方**「叻仔 · 政策问答」**圆形微徽标（58×58px）；
- 市民主动点击徽标时窗口平滑展开，点击右上角「最小化 `-`」或「关闭 `×`」随时缩回，随时随地随用随唤。

### 2. 内置政务级 Markdown 富文本渲染引擎
- **自适应水平滑动表格**：大模型输出的材料清单、审批要求表格自动解析为标准的政务蓝白主题表格（`.lezai-md-table`），外层包裹响应式横向滑动容器（`.lezai-table-scroll`），窄屏或小窗口绝不破损排版；
- **政务多级结构标题**：`#` 至 `####` 自动转换为规范的导办模块分级标题，配备醒目的政务蓝左侧强调装饰竖条；
- **原生 Emoji 与流线导向箭头**：完美保留 `⏱️`、`📋`、`🏠` 等活泼视觉符号，将 `➔` 解析为政务流程指示符；
- **有序与无序清单**：支持粗体重点文字高亮，条理分明。

### 3. 一键直达申报胶囊按钮与外链防拦截
- **智能动作识别**：链接包含“进入 / 申办 / 申报 / 办理 / 直达 / 入口 / 官网”等关键词时，自动升级为高对比度、带 `↗` 图标的**政务蓝白渐变胶囊直达按钮**；
- **裸链接（纯 URL）自动激活**：即便大模型直接输出未包装的网址，系统亦自动转换为可点击的安全链接；
- **跨行断裂自愈缝合**：解决大模型生成文本时可能在 `[标题]` 与 `(URL)` 之间产生换行导致的 Markdown 损坏；
- **穿透宿主 SPA 路由拦截**：通过 `window.open(url, '_blank', 'noopener,noreferrer')` 安全唤起，防止政务网原有路由系统干扰。

### 4. 鼠标滚轮横向平滑滚动（提问记录 & 推荐主题）
- 针对 PC 鼠标只有垂直滚轮的痛点，创新注入 `wheel` 动态映射算法，将鼠标滚轮上下滚动自动平滑转换为横向滑动；
- 鼠标悬停在顶部的**「提问记录」**或底部的**「推荐主题」**上方时，直接滚动滚轮即可顺畅左右浏览全部词条；
- 提问记录容量上限扩充至 10 条，回溯更充裕。

### 5. 提问历史与锚点平滑高亮跳转
- 点击顶部历史标签时，窗口自动**平滑滚动到对应的提问卡片**位置；
- 触发**双层波纹脉冲高亮动效**（市民气泡蓝色发光，AI 回答卡片外框光晕提示），交互直观醒目；
- 智能清洗机制：自动屏蔽并拦截纯数字单字符序号（如多情形选项 `1`、`2`、`3`），避免污染历史记录。

### 6. 右上角一键彻底清空与 360° 旋转动效
- 点击窗口右上角的刷新按钮（🔄），圆环箭头平滑旋转 360 度；
- 同步**清空聊天视窗、清空顶部历史标签栏、清除浏览器 LocalStorage 缓存**；
- 重新生成全局 `sessionId`，切断云端大模型对上一轮提问的历史记忆，真正开启全新会话。

### 7. 物理级隔离与 Mixed Content HTTPS 穿透
- **Shadow DOM 隔离**：使用 `attachShadow({ mode: 'open' })` 构建私有渲染上下文，杜绝宿主政务网站样式污染；
- **穿透 Mixed Content 限制**：在 HTTPS 官方门户（如 `https://www.gz.gov.cn/`）通过 Tampermonkey 的 `@grant GM_xmlhttpRequest`，合法穿透浏览器混合内容安全策略，直连云端服务端。

## 五、 快速安装与使用指南

### 1. 油猴插件安装（推荐，用于官方真实网站）
1. 在 Chrome / Edge / Firefox 浏览器安装扩展：[Tampermonkey（油猴）](https://www.tampermonkey.net/)；
2. 打开 Tampermonkey 面板，点击「添加新脚本」；
3. 打开本项目中的 [gz_gov_ai_assistant.user.js](./gz_gov_ai_assistant.user.js)，**全选复制全部内容**，粘贴覆盖并保存（Ctrl+S）；
4. 打开真实官方政务网站：
   - 广州市人民政府门户网：[https://www.gz.gov.cn/](https://www.gz.gov.cn/)
   - 广东政务服务网广州分厅：[https://www.gdzwfw.gov.cn/?region=440100](https://www.gdzwfw.gov.cn/?region=440100)
5. 网页右下角将出现**「叻仔 · 政策问答」**圆形徽标，点击即可展开智能问答专窗。

### 2. 网页嵌入安装（用于自建门户系统）
在目标网页的 `</body>` 标签前直接引入：
```html
<script src="./gz_assistant_embed.js"></script>
```

## 六、 常见问题与排查指南 (FAQ)

### Q1：把脚本发给同学，为什么同学连不上云端服务？
请按以下 3 步排查：
1. **油猴跨域权限询问**：首次在 HTTPS 网站运行且请求外部 IP 时，油猴扩展会在右上角弹出安全提示：*“xxx 想要连接到 149.118.133.163:6001”*。如果误点了遮罩或“禁止”，通讯会被油猴自身阻断。请在油猴脚本设置中检查并将 `149.118.133.163` 设为**「总是允许」**。
2. **校园网/局域网防火墙限制端口**：让同学在浏览器地址栏打开 `http://149.118.133.163:6001/api/health`：
   - 若返回 `{"status":"UP", ...}`，说明网络通畅；
   - 若一直转圈提示连接超时，说明同学所在 Wi-Fi（如部分校园网、图书馆内网）屏蔽了 6001 端口，让同学切换为**手机热点**即可秒通。
3. **必须通过油猴运行**：广州市人民政府网为 HTTPS 加密站点，若脱离油猴直接在浏览器控制台运行普通 JS，浏览器会直接触发 Mixed Content（混合内容）安全策略强制阻断 HTTP 请求。

### Q2：为什么刚进官网时窗口不自动弹出来？
- 这是我们根据真实用户体验特意设计的**静默待命模式（v3.8.0）**。作为政务级应用，不应该在市民一进入官网时就弹窗遮挡通知公告和首页头条；
- 助手默认收缩在右下角徽标中静默待命，市民只需点击右下角“叻仔”徽标，即可随时唤起。

### Q3：如何调整窗口大小和文字大小？
- **窗口大小**：鼠标拖拽窗口左上角、左边缘或上边缘，即可在 `420×560` 至全屏范围内自由缩放；支持右上角全屏切换按钮；
- **适老化大字模式**：右上角直接提供「大 | 中 | 小」三档字号无级调节，自动持久化记录用户阅读喜好。
